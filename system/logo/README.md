# Logo files

Every file of the Seeds of Renaissance logo. See them all on their grounds, with links, in [the logo files page](../../logos.md). Rules for using them: [logo.md](../../logo.md).

| Folder | What | Formats |
|---|---|---|
| `lockups/` | Mark and name: `horizontal` (the main logo), `two-lines-left`, `two-lines-right`, `stacked`, `wordmark` (name alone) | SVG; transparent PNG 1200 and 2400 px wide |
| `mark/` | The mark alone | SVG; transparent PNG 1130 px |
| `mark/sizes/` | The mark drawn for each size, 16 to 1024 px; `@2x` up to 128 | PNG |
| `favicon.ico` | 16, 32 and 48 px | ICO |

File names end in the colourway: `colour`, `colour-dark` (white bird and name, for dark grounds), `black`, `white`, `red`. For example `lockups/seeds-logo-horizontal-colour.svg`.

- **SVG** is for anything that scales: print, design tools, the web. The bird and the name are vector shapes, so no fonts are needed; the fingerprints are an image inside the SVG, sharp up to about 1130 px (A4 print). Larger than that needs the original fingerprint artwork.
- **PNG** is for anywhere SVG isn't accepted (social profiles, slides, Canva).
- `system/img/logo.png` (600 px) and `logo-256.png` are the same mark, kept at those names because pages and the website link to them; `logo-inverted*.png` are the `colour-dark` mark.

How these were made, and the scripts to rebuild them: [archive/logo-2026-10/](https://github.com/life-itself/design/blob/main/projects/sor-design-system/archive/logo-2026-10/README.md).
