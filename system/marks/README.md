# Marks and patterns

Marks and patterns for Seeds of Renaissance: interlaced and knot marks, a kolam line pattern and checkerboards, as transparent black shapes. Made from [[moodboard/botanical-flower-illustration/removal-candidates|the botanical flower mood board]], where each image was cut out, cropped to a tight box and renamed. See also [[animals/README|animals]], [[mountains/README|mountains]] and [[woodcuts/README|woodcuts]].

Gallery with every file and a link to each: `system/marks/gallery.html` on the design system site (built by `python3 system/build-element-galleries.py` from `elements.json`; it also makes the gitignored `thumbs/`).

Drawn in black ink (`--ink`, `#1b1916`) on a transparent ground. SVGs are kept only where they are small and clean (under 150 KB); the fine concentric cross is PNG only. Catalogue numbers in the sources (5312, 795 and so on) are kept in the names and removed from the images.
