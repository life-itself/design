## Rules

- One graphic moment per section at most. They are punctuation, not wallpaper.
- Keep each set to the colours in the table: woodcuts take the ink of the ground or one of the three [illustration inks](colour.md#illustration-inks-graphics-only); painted and printed sets keep the colours they were made in. Never use a set's own colours on other graphics. Don't outline graphics or add drop shadows.
- One ink per graphic. Two or more on a page is fine if each graphic keeps to one.
- Keep each set to its grounds. Only the woodcuts and the sprite turn chalk on night.
- Don't mix in drawn suns or icon-set icons.
- Elements are cropped close to their edges, so add space in the layout instead of expecting it in the file.
- Registers ([feel.md](feel.md#rigour-and-warmth)) say where a set fits: **Study** (papers, essays), **Conversation** (manifesto, podcast, magazine, landing pages), **Gathering** (community, events).

## The sprite

Include `system/graphics.js` at the top of the body; it inlines the symbols. Then:

```html
<svg class="seed-icon" viewBox="0 0 100 100" aria-hidden="true"><use href="#s-wheat"/></svg>
```

Colour follows `currentColor`: the `.woodcut` class sets ink, and inside `.night` it turns chalk. Every symbol, with its viewBox and code: [the sprite gallery](graphics/sprite.md).

| Symbol | viewBox | Use |
|---|---|---|
| `#wsw` | 0 0 248 150 | The swallow. Single, or three in flight as a flock over a hero (`.flock`, see home.html). |
| `#seal` | 0 0 120 120 | Swallow seal. Closes a long text (`.seal`), or sits in the corner of the night section (`.seal-corner`). |
| `#s-sunflower` | 0 0 100 100 | Seed: **Gather** |
| `#s-wheat` | 0 0 100 100 | Seed: **Practise** |
| `#s-bean` | 0 0 100 100 | Seed: **Belong** |
| `#s-samara` | 0 0 100 100 | Seed (maple key): **Seed / Gardens of Change** |
| `#s-acorn`, `#s-pumpkin`, `#s-stone`, `#s-dandelion` | 0 0 100 100 | Other seeds, free to use |
| `#c-spiral` | 0 0 200 200 | Sunflower spiral, behind a page title (`.page-hero .spiral`) |
| `#c-scatter` | 0 0 280 170 | A handful scattered, above an interlude |
| `#c-row` | 0 0 290 120 | A sown row, as a divider (`.seed-row`) |

The four pathway seeds stay attached to their pathways everywhere: site, thumbnails, slides. Only these symbols are in the sprite; to add a woodcut, put it in `system/graphics.svg` and run `python3 system/build-graphics.py`.

### Black and red

The seeds come in black (ink) and in red (`system/graphics/woodcuts/elements/seeds-red.svg`, the logo red). Spread them across a page to make it more dynamic and personal: to make a quote stand out, as a background, or to punctuate a section. Red woodcuts are the one place red is used as a graphic rather than a link; keep them occasional.

## Files

Every set lives in `system/graphics/<set>/`: the files in `elements/`, the set and its elements described in `elements.json`, and a README on sources and how they were made. The galleries, the cards and the rules table above are built from the `elements.json` files by `python3 system/build-galleries.py`; how to add an element: [system/graphics/README.md](system/graphics/README.md).
