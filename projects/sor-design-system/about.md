# About this site

The Seeds of Renaissance design system: how Seeds of Renaissance looks and sounds, with the rules, files and examples to build from. Version 0.1. It is looked after by the Seeds of Renaissance design team at [Life Itself](https://lifeitself.org).

## Where it lives

Everything here is built from one folder on GitHub: [life-itself/design, `projects/sor-design-system/`](https://github.com/life-itself/design/tree/main/projects/sor-design-system). Each page is a markdown file there, and each page on this site is also served as raw markdown: add `.md` to its URL. AI agents can start from [llms.txt](llms.txt).

## Contributing

- **Spotted something wrong, or need something that isn't here?** [Open an issue](https://github.com/life-itself/design/issues/new) on GitHub, or tell the design team.
- **Changing a page:** edit the markdown file in `projects/sor-design-system/` and open a pull request. Once it is merged to `main`, the site rebuilds and publishes itself within a few minutes.
- **Changing the look:** work it out in an HTML mockup first, then change the tokens in `system/tokens.css` and the guide. How the site is built, and how to change the system safely: [MAINTAINING.md](https://github.com/life-itself/design/blob/main/projects/sor-design-system/MAINTAINING.md).
- **Pages state the rules as they are now.** Work in progress and open questions are tracked in the repository's issue tracker (beads), not on the pages. Brand decisions are recorded in the planning repository, [2608](https://github.com/life-itself/planning/blob/main/projects/2608-seeds-of-renaissance-rebrand.md); design-side decisions in the [decision log](decisions.md).
