Real pages from the current secondrenaissance.net that we will rebuild in the redesign, so the mockups work from real material and not lorem ipsum. These files hold **content only**. The old site's styling is deliberately not carried over.

Snapshotted 2026-09-28. The originals in `secondrenaissance.net/` remain canonical. Text still says "Second Renaissance" where it means the brand, and that needs updating to Seeds of Renaissance when we write final copy.
