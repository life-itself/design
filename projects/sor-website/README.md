## What this project is

The drafting space for the SoR website: what we say and which pages exist. Briefs, copy, section order, nomenclature, and mockups of pages, built from the [SoR design system](../sor-design-system/) without restyling it.

**The real site is built elsewhere:** the `sor-website` repo (sibling of this design repo), on Flowershow, in Markdown. It pulls the design system and these mockups in from a pinned commit of this repo (`scripts/sync-design.py`). Settle a page here, then build it there.

**Split of work**

- **Design system** ([../sor-design-system/](../sor-design-system/)): how things look. Components, tokens, and example pages that show the patterns (content there can be placeholder).
- **This project**: what we say and which pages exist. Briefs, copy, section order, nomenclature and page mockups.
- **`sor-website` repo**: the real, live site.
- **Experiences** ([../sor-experiences-2026/](../sor-experiences-2026/)): ambitious animated pieces. They can be linked from the site or become their own sub-pages, and the site can borrow moments from them.

If a page needs something the system lacks, add it to the system (see [website.md](../sor-design-system/website.md)), not here.

Progress and next steps live in beads (`bd search website`), not in these files.
