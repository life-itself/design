Restora alternatives

Restora is commercial (about $139) and not licensed, so it only shows below where it is installed; elsewhere it falls back to Fraunces. All other faces are open-licence (SIL OFL), free on web, desktop and Canva-style uploads, and load from Google Fonts. Polyamine is a local font and shows only where installed. Each card tests the heading at 24px above Bricolage body at 16px, the real working size, then a billboard-ish line at 45px.
